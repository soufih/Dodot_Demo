# 拖动时按 R 旋转

## 使用方法

普通左键拖动物品或中键取出半栈后，按 R 切换 0°/90° 方向。
每次实际按下切换一次，长按产生的重复事件不连续旋转。
物品必须在配置中允许旋转；不允许时显示提示，预览和数据保持不变。

预览按当前方向显示完整网格占格尺寸，来源或目标是普通栏位时也保持网格尺寸。
落点根据当前预览方向判断；鼠标静止时按 R 后直接松手也可完成放置。
右键、Esc 或无效落点取消时，原物品的位置、数量、方向和版本保持原值。

同类物品仍默认堆叠，保留目标与源余量的原方向；不同物品或 Shift 执行交换。
交换时仅被拖动的物品采用新方向。半栈分割时，仅新栈采用新方向，原栈方向不变。
拖回自身占位格可在原锚点旋转；新矩形放不下时失败且保持原状。

## 实现与接口

UI 仅修改拖拽实例副本和已有预览场景的尺寸，不在按 R 时调用真实旋转命令。
拖拽预览继续实例化 `UI/Inventory/inventory_item.tscn`，没有硬编码创建控件。
只有来源画板处理当前拖拽的 R 事件，拖拽结束后清理引用。
按 R 后通过 Godot 的 `Viewport.update_mouse_cursor_state()` 刷新悬停落点，
该方法的引擎实现会重新处理当前位置的鼠标状态，参见
[Godot Window 实现](https://github.com/godotengine/godot/blob/4.7-stable/scene/main/window.cpp#L876)。

`Services/InventoryService.gd` 保持抽象类；具体服务为原有命令增加可选的
`rotated: Variant = null` 参数。null 保持原方向，bool 指定落地方向：

| Service 方法 | Manager 对应入口 |
| --- | --- |
| `move(from_pos, to_pos, rotated = null)` | `move_in_container`、`switch_to_container` |
| `swap(a_pos, b_pos, rotated = null)` | `swap_in_container`、`swap_between_containers` |
| `split(from_pos, to_pos, quantity = 0, rotated = null)` | `split_in_container`、`split_between_containers` |

Manager 对应方法将方向参数附加在原有参数末尾，已有调用保持兼容。
方向、位置和数量在同一次暂存/提交中校验，跨容器仍使用原有双边事务及回滚机制。
分割拖拽另外保存原方向，用于检查源是否被外部操作改变，避免把预览旋转误判成源变化。

## 测试内容与方法

| 文件 | 内容 | 方法 |
| --- | --- | --- |
| `tests/inventory/drag_rotation_spec.gd` | 两类服务的旋转移动、原位旋转、交换和分割 | 经抽象契约调用，检查实例 ID、数量、方向、矩阵与版本 |
| 同上 | 四种跨服务组合的旋转转移、交换与分割 | 经 Manager 调用并验证通知次数及最终状态 |
| 同上 | 本地及双边提交后失败回滚 | FaultService 注入真实提交后的失败，比较完整快照，检查无成功通知 |
| `tests/inventory/ui_drag_rotation_spec.gd` | R 切换、重复按键、预览实际尺寸、缓存隔离、取消及非拖动状态 | 通过真实输入管线注入键鼠事件，读取引擎挂载的预览与业务快照 |
| 同上 | 鼠标静止时 R 后直接松手、原位旋转、跨类型放置、堆叠与交换 | 完整原生拖拽事件，检查实际锚点、方向及仅一次版本变更 |
| 同上 | 半栈旋转、不可旋转物品、非法落点、大容器滚动后旋转 | 检查新栈方向、来源保留、失败状态及滚动位置 |

执行：

```powershell
.\tests\inventory\run-tests.ps1 -IncludeUI
```

Godot 4.7.2：领域测试 16,749 条断言、UI 测试 372 条断言，失败均为 0。

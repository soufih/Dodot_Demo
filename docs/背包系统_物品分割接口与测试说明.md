# 物品中键分割接口与测试说明

## 操作方法

中键点击数量至少为 2 的物品栈，取出一半作为鼠标拖拽预览；松开中键后预览继续跟随鼠标。
随后左键点击空位完成分割，也可放入能完整接收的同类物品栈。
右键或 Esc 取消；点击不合法落点也会取消，不扣减原栈。
取出后可按 R 旋转允许旋转的半栈预览，放置时仅新栈采用所选方向，原栈方向保持不变。

奇数向下取整，多出的一个留在原栈。例如 9 件分为原栈 5 件与新栈 4 件；
2 件分为 1 件与 1 件；单件物品不能分割。源栈保留实例 ID、锚点、方向及占位；
空位中的新栈获得独立实例 ID，并沿用配置和方向。同类合并保留目标 ID 与方向。

分割拖放只允许空位或可完整接收半栈的同类目标，容量不足时整个分割取消。
分割拖放不交换其他物品；普通左键拖放继续遵守同类堆叠、不同物品交换的规则。
拖拽预览始终使用完整网格占格尺寸，来自普通栏位容器时也保持该尺寸。

## 接口与职责

`InventoryService` 保持抽象契约，具体操作由 `SlotService` 与 `GridService` 实现。
`InventoryStateOps.validate_split` 只校验和计算数量；跨容器提交由现有事务模块协调。
UI 控件和拖拽预览均来自既有 `.tscn`，代码不创建控件。

| 层级 | 接口 | 返回值说明 |
| --- | --- | --- |
| Service | `can_split(pos, quantity = 0)` | 只读预览，成功 payload 为分割数量 |
| Service | `split(from_pos, to_pos, quantity = 0)` | 同容器原子分割放置，成功 payload 为目标实例副本 |
| Service 内部 | `stage_split(staged, pos, quantity = 0)` | 只修改源暂存数量，返回新 ID 的脱离实例 |
| Service 内部 | `stage_place_split(staged, item, pos)` | 在暂存目标完整接收分割实例，返回实际目标副本 |
| Manager | `can_split(id, pos, quantity = 0)` | 对外提供只读预览 |
| Manager | `split_in_container(id, from_pos, to_pos, quantity = 0)` | 路由本地分割 |
| Manager | `split_between_containers(from_id, to_id, from_pos, to_pos, quantity = 0)` | 跨容器事务；ID 相同时路由本地分割 |

接口统一返回 `InventoryResult`。`quantity = 0` 表示对半向下取整；
显式数量必须大于 0 且小于源数量，以保证原栈至少保留一个物品。
失败时不提交暂存计划。跨容器双方全部提交后再通知，每个发生变化的容器版本只加一；
任一提交失败时恢复双方的数量、实例、占位与版本。

中键取出只生成预览，不预扣数据，因此取消无需执行恢复命令。
落地时重新校验容量、占位与来源；原物品被替换、移动、修改数量或旋转后，旧预览不能提交。
原生拖拽的左键确认与右键/Esc 取消机制可参见
[Godot Viewport 实现](https://github.com/godotengine/godot/blob/4.7-stable/scene/main/viewport.cpp)。

## 测试内容与方法

| 文件 | 内容 | 方法 |
| --- | --- | --- |
| `tests/inventory/split_spec.gd` | 两类服务的奇偶分割、非锚点、占位、方向、实例 ID 与副本隔离 | 数量 2～10 的独立配置夹具，经抽象契约调用；比较完整状态 |
| 同上 | 单件、空格、非法数量、边界、碰撞、目标容量不足、自身放回 | 检查错误码、changed 与操作前后快照 |
| 同上 | 四种服务组合、同容器路由、跨容器同类合并、通知和版本 | 经 Manager 集成调用，在首个通知内检查双方已提交 |
| 同上 | 本地及跨容器提交后失败、过期事务和重入 | 使用 FaultService 注入故障，验证恢复完整状态且无成功通知 |
| `tests/inventory/ui_split_spec.gd` | 中键按下/释放、半栈预览、完整占格尺寸、Esc/右键取消、左键放置 | 在真实测试场景注入输入，读取引擎实际拖拽数据与场景预览 |
| 同上 | 奇数、同/跨类型分割、同类合并、选择、非法落点和容量不足 | 比较 Manager 状态与实际视图数量 |
| 同上 | 预览后来源被替换、数量变化或旋转 | 预览期间执行合法命令，再尝试提交旧数据，验证拒绝且不扣错物品 |
| 同上 | 滚动后的中键分割与放置 | 在大容器末端操作，校验完整矩阵坐标和刷新后滚动位置 |

运行全部测试：

```powershell
.\tests\inventory\run-tests.ps1 -IncludeUI
```

领域与 UI 日志分别保存到 `Log/inventory-tests.log` 和 `Log/inventory-ui-tests.log`。
手动测试可运行 `Scene/Inventory/InventoryLab.tscn`，对默认卷轴栈中键取一半，
左键放到空格或同类目标；也可通过添加物品表单准备奇数栈与大容器。
